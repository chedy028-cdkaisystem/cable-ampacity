# Cable Ampacity

MCP tools for Claude that rate power cables (IEC 60287 and Neher-McGrath). This repository is the Claude plugin and marketplace for CDK AI System's hosted Cable Ampacity connector.

The plugin contains only Markdown and JSON. It runs no code on your computer and installs nothing. Calculations run on the hosted CDK AI System server; there is no account and no API key.

## Install

In Claude Code:

```
/plugin marketplace add chedy028-cdkaisystem/cable-ampacity
/plugin install cable-ampacity@cdkai-cable-tools
```

On claude.ai and in Cowork, add it from Customize > Plugins. Then connect the Cable Ampacity connector from the plugin's Connectors tab (claude.ai and Cowork) or check it with `/mcp` (Claude Code).
